## 🚨 严重问题（P0 - 必须修复）

### 1. README文档严重错误
**问题位置**: `README.md`

**问题描述**:
- 文档描述为"五金管理系统"
- 与实际功能完全不符（实际是游戏挂机脚本）
- 会严重误导新开发者

**影响**: 新成员无法理解项目用途，项目维护困难

---

### 2. 线程安全问题 - 全局竞态条件
**问题位置**: `mining.py` - `MultiWindowMiningManager`

**问题代码**:
```python
# 第1149-1165行 - _ensure_window_active 方法
def _ensure_window_active(self, hwnd: int, window_name: str):
    if self._current_active_hwnd != hwnd:
        # 问题：多线程同时访问和修改 _current_active_hwnd
        if self._current_active_hwnd is not None:
            self.logger.info(f"切换窗口: 从...")
        win32gui.SetForegroundWindow(hwnd)
        time.sleep(0.1)
        self._current_active_hwnd = hwnd  # 无锁保护
```

**问题描述**:
- `_current_active_hwnd` 在多线程环境下无锁访问
- `miner.is_mining`, `miner.mined` 等状态标志缺少同步
- 调度器线程和工作线程存在竞态条件

---

### 3. 资源泄漏风险 - 鼠标钩子管理
**问题位置**: `recording.py` - 全局变量和钩子管理

**问题代码**:
```python
# 第64-66行 - 全局变量
mouse_hook = None
mouse_callback = None

# 第179-184行 - 设置钩子
mouse_hook = user32.SetWindowsHookExW(
    WH_MOUSE_LL,
    mouse_callback,
    None,
    0
)
```

**问题描述**:
- 全局鼠标钩子如果程序异常退出可能不会清理
- `__del__` 方法不能保证被调用
- 钩子线程使用 daemon=True 可能导致清理不及时

---

### 4. 异常处理不当 - 裸except捕获
**问题位置**: 全项目，约50+处

**问题代码示例**:
```python
# gui.py 第349-350行
except (AttributeError, TypeError):
    display_text = title

# mining.py 第466行
except (RuntimeError, OSError) as e:
    self.logger.error(f"循环异常: {e}", exc_info=True)

# recording.py 第163行
except (OSError, ValueError) as e:
    self.gui.log(f"鼠标钩子回调错误: {e}")
```

**问题描述**:
- 大量宽泛的异常捕获（`AttributeError`, `TypeError`, `RuntimeError`, `OSError`）
- 捕获后只记录日志，不做恢复处理
- 程序可能继续运行在错误状态
