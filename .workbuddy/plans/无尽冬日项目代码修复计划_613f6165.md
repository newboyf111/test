## 修复方案

### 🔴 阻塞级修复

#### 1. 线程安全问题（mining.py）

**问题**：`_scheduler_running` 在多线程环境下读写不一致
**修复方案**：使用 `threading.Event` 替代布尔标志

```python
# 修改前
self._scheduler_running: bool = False

# 修改后
self._scheduler_running = threading.Event()  # 使用 Event 替代 bool
```

所有读写 `_scheduler_running` 的地方改为：

- 设置：`self._scheduler_running.set()` / `self._scheduler_running.clear()`
- 检查：`self._scheduler_running.is_set()`

#### 2. 鼠标钩子资源清理（recording.py）

**问题**：异常情况下全局鼠标钩子可能未被正确移除
**修复方案**：增加完善的清理机制

```python
def remove_mouse_hook(self):
    """移除全局鼠标钩子"""
    global mouse_hook
    try:
        if mouse_hook:
            result = user32.UnhookWindowsHookEx(mouse_hook)
            if not result:
                error_code = ctypes.get_last_error()
                self.gui.log(f"移除鼠标钩子失败，错误代码: {error_code}")
            mouse_hook = None
    except (OSError, RuntimeError) as e:
        self.gui.log(f"移除鼠标钩子异常: {e}")
    finally:
        # 确保即使异常也清理全局变量
        mouse_hook = None
```

#### 3. pyautogui 安全配置（mining.py）

**问题**：使用 pyautogui 进行点击操作，但没有设置安全配置
**修复方案**：在程序初始化时设置安全配置

```python
# 在 mining.py 模块级别添加
import pyautogui
pyautogui.FAILSAFE = True  # 鼠标移到屏幕角落时抛出异常
pyautogui.PAUSE = 0.1  # 每次操作后暂停
```

### 🟡 建议级修复

#### 4. 代码重复消除（mining.py）

**问题**：`_check_user_stop()` 被调用 30+ 次，代码重复
**修复方案**：使用装饰器封装

```python
def check_user_stop(func):
    """装饰器：在方法开始和关键位置检查用户停止标志"""
    def wrapper(self, *args, **kwargs):
        if self._user_stopped:
            return False if func.__name__ != '_check_user_stop' else True
        return func(self, *args, **kwargs)
    return wrapper
```

#### 5. GUI 模块化拆分（gui.py）

**问题**：gui.py 有 1587 行，文件过大
**修复方案**：拆分为多个模块

- `gui.py`：主入口、初始化、主循环
- `gui_window_manager.py`：窗口选择、激活、调整尺寸
- `gui_mining.py`：挖矿控制、倒计时、队列监控
- `gui_recording.py`：录制功能
- `gui_daily_task.py`：每日任务
- `gui_protective.py`：保护外壳
- `gui_loading.py`：加载界面

#### 6. 日志检查优化（window_manager.py）

**问题**：大量重复的 `if self.logger.isEnabledFor(logging.DEBUG):` 检查
**修复方案**：直接使用 `logger.debug()`，让 logger 自己判断

```python
# 修改前
if self.logger.isEnabledFor(logging.DEBUG):
    self.logger.debug(f"[resize_window] 开始调整窗口 (hwnd={hwnd})")

# 修改后
self.logger.debug(f"[resize_window] 开始调整窗口 (hwnd={hwnd})")
```

#### 8. 魔法数字常量化（mining.py）

class MiningConfig:

#### 9. 异常捕获细化（mining.py）

**问题**：使用 `(RuntimeError, OSError)` 捕获异常，可能掩盖其他问题
**修复方案**：捕获更具体的异常类型

```python
# 修改前
except (RuntimeError, OSError) as e:

# 修改后
except (cv2.error, pyautogui.FailSafeException) as e:
```

#### 10. 全局变量封装（recording.py）

**问题**：使用全局变量存储钩子状态
**修复方案**：将钩子状态封装到类中

```python
class RecordingModule:
    def __init__(self, gui):
        self._mouse_hook = None  # 使用实例变量替代全局变量
```
